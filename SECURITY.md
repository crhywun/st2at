# Security Policy

## Reporting a vulnerability

Use the private vulnerability reporting flow in the GitHub **Security** tab of
this repository. Include the affected version, a minimal reproduction, and the
impact. Do not open a public issue containing live credentials.

## Credentials

`st2at` handles ChatGPT session tokens and access tokens at runtime. Never put
live ST, AT, proxy credentials, or exported account files in an issue, pull
request, test fixture, or commit.
